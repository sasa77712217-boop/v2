# 📘 Centro de Aprendizaje: Ventas y Atención al Cliente

## 📖 Descripción

Este proyecto consiste en un sitio web educativo desarrollado para enseñar conceptos fundamentales sobre ventas y atención al cliente. El objetivo es brindar información organizada, recursos prácticos y herramientas interactivas que permitan mejorar el aprendizaje de los usuarios.

El sitio fue desarrollado utilizando HTML, CSS y JavaScript, aplicando buenas prácticas de desarrollo web, control de versiones con Git y publicación mediante GitHub Pages.

---

## 🎯 Objetivos

- Aprender técnicas básicas de ventas.
- Comprender la importancia de la atención al cliente.
- Practicar mediante un cuestionario interactivo.
- Facilitar el acceso a recursos educativos.
- Demostrar el uso de Git y GitHub en un proyecto real.

---

## ✨ Características

- Página principal con diseño moderno.
- Menú de navegación responsivo.
- Sección de técnicas de venta.
- Sección de atención al cliente.
- Página de recursos.
- Quiz interactivo desarrollado con JavaScript.

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `index.html` o utilizar Live Server.
4. Navegar por todas las secciones del sitio.
